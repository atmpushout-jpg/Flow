Flow

Best-execution swap quotes for AI agents on Base. No API key needed.

What it does

When your agent needs to swap tokens on Base, Flow checks Uniswap V3 and Aerodrome venues and returns the best-execution quote — in about 600ms. Route your quotes through Flow and stop leaving basis points on the table.

Endpoints

POST/api/quote— {tokenIn, tokenOut, amountIn} → best quote
POST/api/fill— execute a quoted swap
GET/api/health— chain status

Try it

curl -X POST https://flow-kg4x.vercel.app/api/quote \
  -H "Content-Type: application/json" \
  -d '{"tokenIn":"0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913",
       "tokenOut":"0x4200000000000000000000000000000000000006",
       "amountIn":"1000000"}'
